# Веб-панель для роутера Huawei E5785Lh-23c

Своя панель управления для E5785Lh-23c с модом bay v5: одна страница со всеми функциями стокового интерфейса и мода,
светлая и темная тема, раскладка для телефона и компьютера. VPN AmneziaWG, обход DPI, шифрованный DNS и блокировка рекламы ставятся пакетами.
Для тех, у кого мод уже стоит и есть доступ root по SSH. Ставится и откатывается одной командой с компьютера, стоковый интерфейс остается на месте.

## Требования

| что | нужно |
|---|---|
| роутер | Huawei E5785Lh-23c |
| прошивка | 21.191.63.02.00 с модом bay v5 |
| доступ | root по SSH, подключение по USB или Wi-Fi |
| компьютер | Linux: `bash`, `python3`, `ssh`, `curl`, `tar`, `xz`, `gzip`, `flock`, `ip` |

Файлов прошивки, мода и стокового веб-интерфейса в комплекте нет. Панель берет с роутера то, что туда поставил мод:

| на роутере | для чего |
|---|---|
| `/system/bin/busyboxx` | команды помощника и установщика |
| `/system/xbin/atc` | команды модему |
| `/app/hijacks/bin/web_hook_client` | вызовы стокового API изнутри роутера |
| `/system/etc/autorun.d/` | автозапуск помощника и пакетов |
| `/system/xbin/wg`, `/system/xbin/openvpn` | WireGuard и OpenVPN на странице VPN |
| `/system/xbin/balong-nvtool` | запись NV: привязка к соте, режим без батареи |
| стоковый веб `/app/webroot/WebApp` | стоковый API и страницы `/html/*.html` |
| `/app/hijacks/bin/sms_webhook_client`, необязательно | чтение номера SIM из SMS оператора помощником; без него номер берет страница |

## Установка

Команды выполняются на компьютере, из корня комплекта.

1. Подключите роутер по USB. Проверьте, что адрес роутера идет через его интерфейс:

   ```bash
   ip route get 192.168.1.1    # ожидается dev wwx001e101f0000
   ```

   Если у интерфейса нет адреса, поставьте службу из [раздела установщика](src/installer/README.md#адрес-компьютера-в-сети-по-usb).
   Другой интерфейс, например Wi-Fi, указывается ключом `--iface=ИМЯ`.

2. Создайте ключ SSH. Сервер на роутере не знает ed25519, поэтому нужен ключ ECDSA или RSA. Если ключ с паролем, добавьте его в `ssh-agent`.

   ```bash
   ssh-keygen -t ecdsa -f ~/.ssh/e5785_key
   ```

3. Добавьте ключ на роутер. Долго удерживайте кнопку меню и выберите пункт «Ключ SSH» (в оригинальном моде и в английском меню — `Add SSH key`). Мод задаст PIN из 6 цифр.
   Войдите один раз под пользователем `pinЦИФРЫ` и примите ключ хоста, роутер запомнит ваш ключ:

   ```bash
   ssh -i ~/.ssh/e5785_key -o HostKeyAlias=e5785-router pinЦИФРЫ@192.168.1.1
   ```

4. Проверьте вход под root:

   ```bash
   ssh -i ~/.ssh/e5785_key -o HostKeyAlias=e5785-router root@192.168.1.1 true
   ```

5. Положите бинарники пакетов на место, сеть не нужна:

   ```bash
   src/pkg/get-bins.sh
   ```

6. Посмотрите, что изменится, и поставьте панель:

   ```bash
   export ROUTER_KEY=~/.ssh/e5785_key
   src/installer/install.sh --dry-run
   src/installer/install.sh
   ```

   Если установщик пишет «НЕ ХВАТАЕТ», ставьте части по отдельности: `--only=web,api`, затем `--only=pkg --pkg-only=ИМЯ` для каждого пакета.

7. Откройте `http://192.168.1.1/` и войдите с паролем веб-интерфейса роутера. Стоковый интерфейс остается на `http://192.168.1.1/html/index.html`.

| переменная | по умолчанию | что задает |
|---|---|---|
| `ROUTER_KEY` | пусто, ключи `ssh` по умолчанию | файл ключа SSH |
| `ROUTER_KNOWN_HOSTS` | `~/.ssh/known_hosts` | файл ключей хостов |

Все ключи `install.sh` — в [src/installer/README.md](src/installer/README.md).

## Откат

| где | команда | что делает |
|---|---|---|
| компьютер | `src/installer/rollback.sh` | отменяет все установки, возвращает файлы до первой установки |
| компьютер | `src/installer/rollback.sh --last` | отменяет только последнюю установку |
| роутер | `busyboxx sh /online/mod/mod-uninstall.sh` | то же без компьютера, ключи `--last` и `--dry-run` |
| роутер | `busyboxx touch /online/mod/disabled` | выключает автозапуск помощника и пакетов, файлы остаются |

Откат не трогает `/online/scripts`, профили VPN и файлы мода.

## Устройство

```text
браузер ── http://192.168.1.1/ ──► веб-сервер роутера (/app/bin/web, uid 1000)
                                     ├─ стоковый API /api/...       ── настройки, SMS, Wi-Fi, сеть
                                     └─ POST /api/vsim/config-vsim  ── функции панели (поле module)
                                            └─ очередь /var/modq ──► помощник qd (root)
                                                   └─ iptables, AT, скрипты, VPN, службы
```

- Страница панели отдается на корень `/` вместо `/app/html/redirect.html`, скрипты и стили — из `/js/mod/` и `/css/mod/`.
- Веб-сервер запускает обработчики Lua, они пишут запрос в очередь, помощник от root его выполняет.
- Сторож `wd` раз в 30 с проверяет помощника и перезапускает его, если очередь не отвечает.

## Ограничения

- Веб-сервер пускает только пути из подписанного `restfulconfig_common.xml`. Поэтому все свои вызовы идут через незанятый путь `/api/vsim/config-vsim`: виртуальной SIM на 23c нет.
- Страницы `/html/*.html` веб-сервер отдает только из подписанного списка. Поэтому панель стоит на корне `/`, а адреса вроде `/html/mod.html` нет.
- Веб-сервер не раздает `.woff2`, а его CSP запрещает шрифты из `data:`. Поэтому шрифты лежат файлами `font-geist-*.css`.
- Веб-сервер обрабатывает запросы по одному. Пока идет долгий вызов, не отвечает весь веб, стоковый тоже. Долгое идет в фоне, страница опрашивает результат.
- Процессы от uid 1000 не могут открыть сокет: в ядре сокеты есть только у root и групп 3003 и 3004. Поэтому помощник слушает очередь файлов, а не порт.
- Из `/sys/class/thermal` панель читает только 4 датчика: `battery`, `sim_card1`, `pa0`, `xo0`. Чтение остальных каналов на некоторых NV вызывало ложную защиту от перегрева и выключение роутера.
- Переключатели «Опасные настройки» (`modem_write`, `nv_write`) по умолчанию выключены. Без них не работают смена режима модема, диапазонов, привязка к соте и режим без батареи.
- Модуль ядра `amneziawg.ko` необязателен: без него туннель держит `amneziawg-go`. Модуль собран под ядро 3.10 этой прошивки и в других прошивках не работает.
- Ставьте вариант NEON: md5 `6650d98a006f25c1edf326693b81125a`, sha256 `f2b6991c0aa2895cd6b5e4c234cbf8732cff922ab8082ff999aad1101fc6afff`. Он прошел прогон на роутере. Первая сборка NEON вызывала ошибку ядра `BUG`, ее ставить нельзя.
- Модуль `amneziawg.ko` нельзя выгружать: `rmmod` вызывает панику ядра. В очереди модема могут лежать пакеты с деструктором `__compat_fake_destructor` из кода модуля. Снять модуль можно только перезагрузкой.
- Перед загрузкой модуля `svc.sh` записывает `kernel.panic=5`: при панике роутер перезагрузится сам через 5 с, это действует до перезагрузки.
- Смена IMEI не поддерживается: консоль AT блокирует такие команды, запись NV и прошивку.
- На `/online` мало места: все пакеты занимают 13,3 МиБ, при замене вдвое больше. Ставьте пакеты по одному.
- `zapret2` и `tpws` вместе не включайте: соединения дважды попадают в обработку.
- Обход DPI не помогает против блокировки по IP и белых списков оператора.
- Раздельный VPN выбирает маршрут по адресу. Сайт на зарубежном CDN идет через туннель, сайт на российском адресе — напрямую, и блокировка оператора для него остается. Домены в исключениях не поддерживаются, только адреса и подсети.
- Для раздельного VPN нужен свой список российских адресов: это данные RIPE NCC, по условиям RIPE комплект их не распространяет. Как собрать его на компьютере и загрузить кнопкой из панели — [src/pkg/awg/tools/README.md](src/pkg/awg/tools/README.md). Без списка режим не действует: это обычный полный VPN.
- Сам роутер по умолчанию идет мимо туннеля (`ROUTE_SELF=0` в `src/pkg/awg/conf`), в туннеле только клиенты LAN.
- На роутере `/dev/random` равен `/dev/urandom`. Иначе OpenSSL на ядре 3.10 ждет `/dev/random` 2–3 минуты после включения, и DoT в это время не работает. Перед заменой `mod-ctl.sh boot` подмешивает файл `/online/mod/conf/random-seed`. Файл создается на самом роутере и в комплект не входит. Файла нет — `/dev/random` не меняется, и задержка остается до следующей загрузки.
- Примерно полминуты после включения заблокированные сайты могут не открываться: служба DNS еще не запущена, клиентам отвечает DNS оператора или никто.
- Предел туннеля на роутере — 41–46 Мбит/с при упоре в процессор на нескольких соединениях. Одно соединение обычно дает заметно меньше.
- Обычный DNS (порт 53) через 8.8.8.8 и 1.1.1.1 на Tele2 перехватывается оператором. Поэтому в пресетах пакета `dns` только DoT, DoH и DNS оператора.
- На 23c нет проводного порта, SD-карты, моста, SIM Toolkit, SMS-вещания, IPv6, VoLTE, выбора антенны и обновления прошивки онлайн.
- 5 ГГц и гостевая сеть выключены: `api/wlan/wifi-feature-switch` отвечает `wifi5g_enabled=0`, `guestwifi_enable=0`, страница Wi-Fi показывает диапазон 2,4 ГГц. В наборе настроек модели `/app/config/E5785Lh-23c/wifi/config.xml` стоит `1`, но этот набор на роутере не применен.
- `/online` принадлежит uid 1000, поэтому процесс с этим uid может подменить `/online/mod` и получить root.
