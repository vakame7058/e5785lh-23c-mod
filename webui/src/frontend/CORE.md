# Каркас SPA: сборка, мок, объект `M`

Для тех, кто пишет страницы в `pages/`: как собрать панель, запустить мок и чем пользоваться в каркасе.

## Сборка и мок

```bash
cd src/frontend
python3 build.py                 # dist/js/mod/app.js, dist/css/mod/app.css, оболочка и .gz
python3 build.py --no-min        # без сжатия app.js (отступы и комментарии на месте)
python3 build.py --watch         # пересобирать при каждом сохранении
python3 dev/server.py --pidfile /tmp/mywebui-dev.pid   # http://127.0.0.1:8097/ — мок API, вход с любым паролем
python3 dev/server.py --proxy http://192.168.1.1   # API настоящего роутера
```

Мок слушает порт 8097 (`--port` меняет). Остановить свой сервер —
`kill $(cat /tmp/mywebui-dev.pid)`; `pkill -f` с тем же шаблоном в командной строке убивает и саму оболочку.

Оболочка SPA на роутере открывается на корне «/»: установщик ставит ее вместо `/app/html/redirect.html`,
копия лежит в `/js/mod/index.html`. Страницы `/html/*.html`, кроме стоковых, роутер не отдает (список подписан).
Веб роутера вставляет два `<meta name="csrf_token">` сразу после `<head>`; каркас берет первые токены из них.
Мок делает так же: оболочка на «/», `/js/mod/index.html` и `/html/mod.html`, два мок-токена после `<head>`.
Все пути в `index.html` абсолютные: `/js/mod/app.js`, `/css/mod/app.css`. Стоковый интерфейс остается на `/html/index.html`.

| файл сборки | путь на роутере |
|---|---|
| `dist/html/mod.html` | `/app/html/redirect.html` (открывается на «/») |
| `dist/js/mod/index.html` | `/js/mod/index.html` |
| `dist/js/mod/app.js(.gz)` | `/js/mod/app.js` |
| `dist/css/mod/app.css(.gz)` | `/css/mod/app.css` |
| `dist/css/mod/font-geist-sans.css(.gz)`, `font-geist-mono.css(.gz)` | `/css/mod/font-geist-*.css` (шрифты Geist в формате woff2 под именем `.css`; лицензия — комментарием в начале `app.css`) |

Прокси включается, только если маршрут до адреса роутера идет через USB-интерфейс `wwx001e101f0000`
(`ip route get 192.168.1.1`). Иначе сервер пишет «ВНИМАНИЕ: прокси выключен» и работает на моке:
адрес 192.168.1.1 может принадлежать чужой сети Wi-Fi. Другой интерфейс — `--proxy-dev ИМЯ`.

| файл | что это |
|---|---|
| `core/*.js` | каркас, склеивается первым по имени файла |
| `pages/*.js` | страницы, склеиваются после каркаса по имени файла |
| `css/*.css` | стили, по имени файла |
| `index.html` | оболочка, в сборке `dist/html/mod.html` |
| `fonts/` | шрифты Geist (npm `geist` 1.7.2, подрезаны `dev/fonts.py`: латиница, кириллица, знаки) и `OFL.txt` |
| `dev/mock/stock/<путь>.xml` | ответ мока на `GET /api/<путь>` |
| `dev/mock/mod/<имя>.xml` | ответ мока на `GET /api/mod/<имя>` |
| `dev/mock/mod/<имя>.<action>.xml` | ответ мока на `POST /api/mod/<имя>` с этим `action`; если файла нет — `<имя>.post.xml`, иначе `<response>OK</response>` |
| `dev/mock/stock/config/<путь>` | ответ на `GET /config/<путь>` (файлы настроек веба, например `config/wifi/countryChannel.xml`) |
| `dev/mock/mod/_stock/<путь>.xml` | запасной ответ на `GET /api/<путь>`, если в `dev/mock/stock/` файла нет (моки стока для страниц из `pages/`, которые пишет не владелец каркаса) |
| `dev/mock/stock/<путь>.post.xml`, `dev/mock/mod/_stock/<путь>.post.xml` | ответ на `POST /api/<путь>` (например, `sms/sms-list`) |

Сборка сжимает `app.js` построчно: убирает пустые строки, строки-комментарии `//` и отступы.
Переводы строк и содержимое шаблонных строк остаются. Комментарий в конце строки с кодом тоже остается.

Каждый файл `.js` при сборке оборачивается в свою функцию с `'use strict'`: переменные одного файла
не видны в другом, общее — только через `M`. `node --check` проверяет синтаксис собранного `app.js`.

Мок отвечает `100002`, если файла ответа нет. `POST` на стоковый путь без файла `<путь>.post.xml`
отвечает `OK` и запоминает плоские поля: следующий `GET` того же пути вернет их. Без входа мок
отвечает `100003` на все, кроме путей, которые и роутер отдает без входа. Токены проверяются,
как на роутере: `POST` без годного токена получает `125001`.

| ключ `dev/server.py` | что делает |
|---|---|
| `--login` | сразу «вошли» |
| `--open` | все пути отвечают без входа |
| `--delay МС` | задержка каждого ответа API |
| `--password ПАРОЛЬ` | пароль, для которого мок считает настоящий SCRAM (по умолчанию `admin`); любой другой тоже пускает |
| `--build` | собрать перед запуском |
| `--pidfile ФАЙЛ` | записать PID сервера, чтобы остановить его по PID |
| `--proxy-dev ИМЯ` | интерфейс, через который должен идти маршрут к роутеру (по умолчанию `wwx001e101f0000`) |

`GET /dev/state` показывает последние `POST` (в том числе расшифрованные тела `;enc`).

## Страница

```js
M.page({ id: 'sms', title: 'SMS', group: 'Сообщения', icon: 'sms', order: 30,
         render: async (el, ctx) => { … }, destroy: () => {} });
```

| поле | по умолчанию | что делает |
|---|---|---|
| `id` | — | адрес `#/id` |
| `title` | — | пункт меню и заголовок в шапке |
| `group` | без группы | группа меню; группы идут по наименьшему `order` своих страниц |
| `icon` | `dot` | имя иконки из `M.icons` |
| `order` | 100 | порядок в группе |
| `menu` | `true` | `false` — страница есть по адресу, но не в меню |
| `public` | `false` | `true` — открывается без входа, без меню и шапки (экран входа) |
| `visible` | — | функция; `false` — скрыть пункт меню (например, по `M.state.features`) |

`ctx` — объект с полями:

| поле | что это |
|---|---|
| `api`, `mod`, `ui` | `M.api`, `M.mod`, `M.ui`; в `ctx.ui.poll` опрос привязан к этой странице |
| `params` | параметры адреса: `#/sms?box=2` → `{box: '2'}` |
| `rest` | части пути после `id`: `#/sms/5` → `['5']` |
| `onLeave(fn)` | вызвать `fn` при уходе со страницы |
| `setTitle(текст)` | сменить заголовок в шапке |
| `go(id, params)` | перейти на страницу |

Порядок меню: сначала страницы без группы, затем группы по наименьшему `order` своих страниц.

| `order` | группа | страницы |
|---|---|---|
| 1–9 | без группы | `home` 1, `signal` 2 |
| 10–99 | Сеть | `network` 10, `wifi` 20, `clients` 30; дальше `stats` 210, `lan` 220 |
| 100–199 | Сообщения | `sms` 110, `ussd` 120 |
| 300–399 | Безопасность | `firewall` 310, `vpn` 320 |
| 400–499 | Улучшения | `tweaks` 410 … `speedtest` 450 |
| 500–599 | Система | `system` 510, `stock` 590 |

Если `render` бросает исключение, каркас показывает текст ошибки и кнопку «Повторить».
Пока `render` не завершился, под шапкой бежит полоска загрузки.

## API

| вызов | что делает |
|---|---|
| `M.api.get('api/device/signal')` | объект из `<response>`; ведущий `/` не обязателен |
| `M.api.post(путь, объект, {encrypt: ['password']})` | `POST` с `<request>…</request>`, ответ — объект или строка `OK` |
| `M.api.post(путь, объект, {enp: ['WifiWpapsk']})` | шифрует RSA только эти поля, как `enp` у стока (пароль Wi-Fi) |
| `M.api.get(путь, {errors: {113018: 'текст'}, timeout: мс})` | свои тексты кодов для этого вызова; время ожидания (по умолчанию 30 с) |
| `M.api.secrets('wlan')` | секреты, которые сток отдает только шифрованными (`api/user/pwd`, ответ в AES): `Ssids.Ssid[].WifiWpapsk` |
| `M.api.ok(ответ)` | `true`, если ответ — `OK` |
| `M.mod('cell')` | `GET /api/mod/cell` |
| `M.mod('cell', 'lock', {pci: 1})` | `POST /api/mod/cell` с `<action>lock</action><pci>1</pci>` |
| `M.arr(x)` | всегда массив: один элемент списка в XML приходит объектом |
| `M.xml.build(obj, 'request')`, `M.xml.parse(text)` | XML вручную |

- Ошибка — исключение `M.ApiError` с полями `code` (строка), `message` (русский текст), `data` (прочие поля `<error>`).
- Общая таблица `M.errors` знает только коды, которые у стока значат одно и то же везде (`100xxx`, `108xxx`, `125xxx`).
  Коды разделов (SMS `113018` — «система занята», USSD `111019`/`111020` — «ответа еще нет»/«оператор не ответил»)
  переводит страница: `{errors: {…}}` в вызове. Если текста нет — берется `<message>` ответа, иначе «Ошибка роутера, код N».
- `encrypt` — список секретных полей или `true`. Если роутер включил шифрование
  (`module-switch` `encrypt_enabled=1`), тело запроса шифруется RSA целиком, как у стока (`enc:true`).
  Поля по отдельности сток не шифрует.
- Булевы значения в объекте запроса уходят как `1`/`0`, массивы — повтором элемента, `null` и `undefined` пропускаются.
- `POST` идут по одному: токен одноразовый, следующий приходит в заголовке ответа.
- Коды `125002`, `125003`, `100003` запускают проверку входа; если сессии нет — экран входа
  с возвратом на текущую страницу после входа.

## M.ui

Договор (`el`, `card`, `kv`, `table`, `form`, `btn`, `toggle`, `toast`, `confirm`, `spinner`, `badge`, `meter`, `poll`)
выполнен. Подробности и добавленное:

| вызов | что делает |
|---|---|
| `el(tag, attrs, ...дети)` | `attrs`: `class` (строка или массив), `style` (строка или объект), `onclick` и прочие `on*`, `dataset`, `text`; `value`, `checked`, `disabled` ставятся свойством. Дети — строки, узлы, массивы; `null` и `false` пропускаются |
| `card(заголовок, ...дети)` | заголовок — строка или `{title, sub, icon, actions: [кнопки, значки]}`; `.setActions([…])` меняет действия |
| `kv(строки)` | строки — `[[название, значение, подсказка?], …]` или объект; пустое значение — «—»; `.update(строки)` перерисовывает |
| `table(колонки, строки, opts)` | колонка — строка-ключ или `{key, title, render(row, i), cls, width}`; `opts`: `empty` (текст), `onRow(row)`, `rowClass(row)`; `.update(строки)`. На узком экране строки становятся карточками |
| `form(поля, onSubmit, opts)` | см. ниже |
| `btn(текст, onClick, вид, {icon, title, disabled, class})` | вид: `primary` (основная, одна на экран), `danger` (вторичная с красным текстом), `ghost` или пусто (вторичная); пока `onClick` работает — кнопка занята, исключение — в `toast` |
| `toggle(текст, значение, onChange, {hint, disabled})` | `onChange(новое)` может вернуть `false` или бросить — переключатель вернется назад; `.set(v)`, `.value` |
| `toast(текст, вид)` | вид: `ok`, `err`, `warn`, `info` |
| `confirm(текст, {title, ok, cancel, danger})` | `Promise<boolean>`; с `danger` кнопка подтверждения красная — единственное место с красной заливкой |
| `modal(заголовок, содержимое, кнопки, {sticky, onClose})` | кнопка — `{label, kind, value, onClick}`; `onClick` вернул `false` — окно не закрывается; возвращает `{el, close}` |
| `meter(v, min, max, подпись, {fmt, good, bad})` | полоса с цветом по порогам; `good > bad` — больше лучше; `.set(v)` |
| `poll(fn, мс, {onError, hidden})` | `fn` сразу и каждые `мс`, без наложения; пауза, пока вкладка скрыта; стоп при уходе со страницы; возвращает `{stop, now, setInterval}` |
| `badge(текст, вид)` | вид: `ok`, `warn`, `err`, `info`, `muted` |
| `spinner(текст)`, `empty(текст, иконка)`, `notice(текст, вид)` | ожидание, пустой список, сообщение в рамке |
| `pre(текст)` | моноширинный вывод (логи, ответ команды); `.set(текст)` прокручивает вниз |
| `stat(подпись, значение, под, {icon})` | крупное число с подписью; `.set(значение, под)` |
| `grid(...)`, `row(...)` | сетка карточек; строка кнопок (переносится, за край карточки не выходит) |
| `dnsWarn(ctx)` | предупреждение «VPN включен, служба DNS выключена» для карточки VPN и «Сводки»: `{el, update({vpnUp, dnsTunnel})}`, кнопка «Включить DNS» (svc `dns_enable`), скрытие крестиком только при `user_off=1`; `running=0`, `enabled=1`, `user_off=0` — «DNS не запустился: `last_error`. Устройства сейчас спрашивают DNS оператора», и при выключенном VPN тоже; строка по `dns_upstream`: `backup` — «работает запасной сервер», `operator` — «DNS оператора: заблокированные сайты не откроются» |
| `actionRow(название, пояснение, кнопка)` | строка действия: слева название и пояснение, справа компактная кнопка; на узкой карточке кнопка уходит под текст. Для карточек из нескольких разовых действий («Перезагрузка и сброс») |
| `stats(...)` | ряд показателей `stat` (2–4 в ряд, на телефоне по два) |
| `subhead(текст)` | подзаголовок внутри карточки |
| классы `grid`, `cols` | кладка колонками-стопками (колонка от 400 px: на 1366 — две, на 1920 и шире — три, на телефоне — одна; две карточки — две колонки); карточка своей высоты, пустых низов нет; порядок — сверху вниз по колонкам |
| `stacks([а, б, в], [г])` | явные стопки: страница сама решает, что в какой колонке; на телефоне — одна колонка по порядку |
| `stacks21(большая, малая)` | колонки 2/3 и 1/3 от 1300 px окна; уже — одна колонка, элементы с классом `stack-last` внизу |
| `split(левая, правая, {big})` | две колонки содержимого внутри широкой карточки (от 1000 px ее ширины, `big` — 3:2); уже — стопкой; правая пуста — левая на всю ширину |
| классы `grid-2`, `grid-3` | ряды плиток от 420 и от 260 px, без растягивания по высоте |
| класс `stack` | столбец с отступом 12 px |
| `toggle-row` подряд | вне `.card-b` получают отступ 6 px сами |
| `bars(n, max)` | столбики уровня сигнала |
| `tabs([[id, текст], …], onChange(id), активная)` | полоса вкладок; элемент — `{id, label, icon, badge}`; `.set(id)`, `.value`; содержимое вкладок ведет страница |
| `chart({height, min, max, auto, zero, points, phaseBand, noLegend, series: [{name, cls}], fmt})` | линейный график SVG; `.update([[ряд1], [ряд2]])`, `null` — пропуск; `.setPhases([{at, label или lines, short, cls}])` — разделитель перед точкой `at` и подпись фазы над линиями (место под подпись — `phaseBand`; `lines` — две строки, `short` — короче, если мало места) |
| `clear(узел)`, `add(узел, дети)`, `errMsg(e)`, `icon(имя, размер)` | мелочи |

Форма: поле — `{name, label, type, value, options, hint, placeholder, required, min, max, maxlength, pattern,
disabled, validate(v, все) → текст ошибки, show(все) → видно ли, wide, attrs}`.

| `type` | значение в `values()` |
|---|---|
| `text`, `password`, `textarea` | строка (`text` без пробелов по краям) |
| `number` | строка; проверка на число и `min`/`max` |
| `select` | строка; `options` — `[[значение, подпись]]`, `[{value, label}]`, `['a', 'b']` или объект |
| `toggle` | `true`/`false` |
| `checkbox` | `true`/`false`; галка с текстом `text` справа, без колонки подписи; `disabled` и `hint` — почему недоступна |
| `static` | не попадает в значения, только показывается |

`onSubmit(values, form)`: исключение — текст под формой и `toast`; вернул `false` — без «Сохранено».
`opts`: `submit` (текст кнопки или `false`), `primary` (`true` — основная кнопка; по умолчанию вторичная),
`actions` (узлы рядом с кнопкой), `silent`, `done` (текст `toast`).
На карточке шире 560 px подписи стоят колонкой 184 px, поле — до 440 px; на узкой карточке подпись над полем.
Методы формы: `values()`, `set(имя, v)`, `setAll(объект)`, `setOptions(имя, options)`, `field(имя)`, `row(имя)`, `error(текст)`, `busy(b)`.

## Оформление

Цвета — токены Geist (vercel.com/geist/colors), шрифты Geist и Geist Mono (OFL, `fonts/OFL.txt`).
В страницах цвета и размеры не задаются числами: только переменные из `css/00_base.css`.

| переменная | светлая | темная | где |
|---|---|---|---|
| `--bg` | `#fafafa` | `#000000` | фон страницы |
| `--surface` | `#ffffff` | `#0a0a0a` | карточки, поля |
| `--surface-2` | `#f2f2f2` | `#1a1a1a` | наведение, подложки |
| `--border` | `#ebebeb` | `#2e2e2e` | рамки |
| `--border-2` | `#c9c9c9` | `#454545` | рамки полей |
| `--text`, `--text-2`, `--text-3` | `#171717`, `#4c4c4c`, `#8f8f8f` | `#ededed`, `#a1a1a1`, `#8f8f8f` | текст, второстепенный, подсказки |
| `--primary` / `--on-primary` | `#171717` / `#fff` | `#ededed` / `#0a0a0a` | основная кнопка (инверсная) |
| `--accent`, `--accent-2` | `#0068d6`, `#0072f5` | `#52a8ff`, `#0072f5` | ссылки; фокус, переключатели, выбранное |
| `--ok`, `--warn`, `--err` | `#297a3a`, `#a35200`, `#cb2a2f` | `#62c073`, `#f2a20d`, `#ff6166` | смысловой текст и значки |
| `--ok-bar`, `--warn-bar`, `--err-bar` | `#45a557`, `#ffb224`, `#e5484d` | те же | тонкие полосы шкал |
| `--err-fill` | `#da2f35` | `#d93036` | только кнопка подтверждения опасного действия |

Раскладка страницы:

- широкие и главные блоки — сверху, на всю ширину (`Проброс портов`, AmneziaWG) или большой колонкой 2/3 с малой колонкой рядом (`stacks21`);
- в широкой карточке нет пустой половины: содержимое идет в две колонки `split`, например таблица и форма, список и график;
- мелкие карточки настроек — ниже, кладкой колонок (`ui.grid`), одна кладка на страницу;
- ни одной карточки на всю ширину посреди кладки: она рвет колонки и дает дыры;
- карточка своей высоты и не тянется до соседей; промежуток в стопке равен промежутку между колонками;
- карточка на всю ширину без второй колонки — только с таблицей, графиком или полем текста; строки формы, пары
  «подпись — значение» и переключатели в ней не шире 760 px (запасное ограничение, проверка `ui2_test` считает пустоту сбоку ошибкой);
- ничего не шире своей колонки: длинный текст переносится, широкая таблица прокручивается внутри карточки;
  ряды кнопок (в заголовке, под формой, `row`) переносятся, кнопка не шире карточки;
- несколько разовых действий в одной карточке — каждое своей строкой `actionRow`, а не рядом кнопок.

Отступы — шкала `--s1`…`--s6` = 4, 8, 12, 16, 24, 32 px. Промежуток между карточками `--gap` 16 px (на телефоне 12),
поля страницы `--pad` 24 px (на телефоне 16), поля карточки `--card-pad` 16 px. Контент от левого края с полями,
шириной до 1760 px. Радиусы: кнопки и поля 6 px, карточки и окна 12 px. Теней нет, разделение рамками.

Боковое меню без подвала: переключатель темы — кнопкой в шапке рядом с выходом. Пункт меню 30 px, все 19 пунктов
помещаются на экран высотой 800 px; на низком экране список прокручивается, низ плавно гаснет.

Действия карточки («Новое сообщение», «Обновить», «Добавить», «Сбросить счетчики», «Найти сети», «Скорость через туннель»)
стоят справа в строке заголовка, компактные: `ui.card({title, actions: [кнопки]})`, после смены состояния —
`card.setActions([…])`. Главное действие — `primary` (одно на экран), второстепенные — `ghost` или значком
с подсказкой (`title`). На телефоне второстепенные сворачиваются в «…», значки состояния (`badge`) остаются на месте.
Кнопки формы («Сохранить», «Применить») стоят под формой слева.

Форма на всех страницах: подпись слева, поле или переключатель справа у края карточки (поле до 440 px и не шире
60 % строки); на карточке уже 480 px и на телефоне подпись над полем.

Правила для страниц:

- Одна основная кнопка на экран — главное действие страницы. Остальные вторичные.
- Опасное действие (сброс, удаление, перезагрузка) — вторичная кнопка, красная заливка только в окне подтверждения.
- Переключатель применяется сразу и откатывается при ошибке; поля ввода сохраняются кнопкой.
- Красный, зеленый и желтый — только смысл: значки, текст состояния, тонкие полосы. Больших цветных заливок нет.
- Числа — `font-variant-numeric: tabular-nums` (класс `num`) или моноширинный шрифт.

## Прочее в M

| вызов | что делает |
|---|---|
| `M.state.status` | последний `api/monitoring/status` (каркас опрашивает раз в 5 с после входа) |
| `M.state.plmn` | последний `api/net/current-plmn` |
| `M.state.features` | `api/global/module-switch` (`sms_enabled`, `wifi_enabled`, `encrypt_enabled` …) |
| `M.on('status', fn)` | событие после каждого опроса состояния; возвращает функцию отписки |
| `M.on('login' / 'logout', fn)` | вход и выход; после выхода каркас сам открывает экран входа |
| `M.go(id, params)` | перейти |
| `M.banner(текст, вид)` | сообщение над страницей; пустой текст — убрать |
| `M.ui.speedPanel(ctx, {tunnel})` | замер скорости роутером: `run(args, сек)`. Один график на замер: фазы «Прием» и «Отдача» подписаны на нем с итогом, между ними разделитель, отдача сглажена средним за 1 с; ниже ЦП; рядом таблица результата. Вывод о процессоре: напрямую — «упирается» при средней от 90 % или 90 % и больше у более чем половины точек, «близко к пределу» от 75 %. Через VPN (`tunnel` или `via` в ответе): «упирается» — так же; «возможно, близка к пределу» — при 90 % и больше у 20–50 % точек или средней от 70 %; иначе «скорость ограничивает задержка до сервера VPN или его канал». Отдача не удалась (`up_status=error`): в таблице «Отдача: текст `up_error`», прием показан; способ отдачи (`up_mode`, `up_requests`, `up_connections`) — строкой «Как шла отдача». Пока идет замер, опрос `show` раз в 3 с, остальные опросы страницы и шапки ждут (`M.quiet`): запросы сами отнимают скорость. Под итогом — «Разгон первых 2 секунд не учитывается», в таблице «Трафик замера». Несколько потоков (`streams` от 2): четыре фазы на том же графике («Прием», «Прием N потока», «Отдача», «Отдача N потока»), строки итога `mt_kbps`, `up_mt_kbps`, вывод о процессоре по каждой фазе, причина из `mt_error`, `up_mt_error`. Методы: `el, show, run, follow, note, setBig, setServers, busy` |
| `M.ui.simNumber(ctx)` | блок «Номер SIM» (`M.mod('msisdn')`): номер, состояние запроса у оператора (`auto_state`), кнопки «Узнать у оператора» (`query`, USSD шлет помощник) и «Изменить» (ручной ввод, 10–15 цифр) |
| `M.on('sysinfo', fn)` | загрузка ЦП, когда страница сама читает `sysinfo` (так шапка показывает «ЦП N%» без своего опроса) |
| `M.keepAwake(true)` | не выходить по бездействию, пока открыта страница (сбрасывается при уходе) |
| `M.store.get(ключ, по умолчанию)`, `M.store.set(ключ, v)` | `localStorage` в JSON с защитой от запрета хранилища |
| `M.fmt.bytes(n)`, `speed(байт/с)`, `duration(с)`, `db(x, ед.)`, `num(v, знаков)` | числа для людей |
| `M.netType(status)` | `2G`, `3G`, `4G`, `4G+` по `CurrentNetworkType(Ex)` |
| `M.icons`, `M.icon(имя)` | иконки; свои — `M.icons.имя = '<path d="…"/>'` (SVG 24×24, линия) |

## Ограничения

- Роутер запрещает `data:` в CSS и картинках (заголовок `Content-Security-Policy`). Иконки — только встроенный SVG.
- Мок считает SCRAM и расшифровывает RSA OAEP той же схемой, что сток.
- Выход по бездействию — через `api/time/timeout` минут без действий пользователя, как у стока.
