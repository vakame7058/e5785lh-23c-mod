# Список адресов для раздельного VPN

Как получить на компьютере список российских адресов и загрузить его на роутер. Для того, кто включает раздельный VPN в пакете `awg`.
Как работает сам режим — раздел «Раздельный VPN» в [README пакета](../README.md).

Списка в комплекте нет: это производные данные RIPE NCC, а условия RIPE разрешают распространять данные только без изменений.
Без списка режим не действует, туннель работает как обычный полный VPN.

## Как получить и загрузить список

Команды выполняются на компьютере, из корня комплекта. Нужен `python3`.

1. Скачайте файл статистики RIPE NCC:

   ```bash
   curl -O https://ftp.ripe.net/pub/stats/ripencc/delegated-ripencc-extended-latest
   ```

2. Соберите список:

   ```bash
   python3 src/pkg/awg/tools/split-gen.py delegated-ripencc-extended-latest ru-list.txt
   ```

   Ожидаемый вывод: `ru-list.txt: N префиксов, дата ГГГГ-ММ-ДД`.

3. Откройте в панели страницу VPN, раздел раздельного VPN, и нажмите «Загрузить файл».
4. Выберите `ru-list.txt`. Панель покажет дату списка и число префиксов.

Чтобы обновить список, повторите эти шаги. Сам роутер его не скачивает.

## Ключи `split-gen.py`

| ключ | по умолчанию | что делает |
|---|---|---|
| `--country=КОД` | `RU` | код страны |
| `--min-prefix=ДЛИНА` | не укрупнять | укрупнить префиксы длиннее этой длины, например `22`: маршрутов меньше, лишних адресов больше |

Скрипт ничего не скачивает и не обращается к роутеру. Страна в списке — страна делегирования адреса, а не место работы сайта.
