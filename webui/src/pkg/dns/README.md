# dns: блокировка рекламы и шифрованный DNS

DNS-запросы клиентов LAN перенаправляются на свой dnsmasq; стоковый DNS роутера не меняется.
dnsmasq отвечает `0.0.0.0` на домены из списка рекламы, остальное пересылает дальше и кэширует.
Сервер выбирается пресетом. В шифрованных пресетах dnsmasq пересылает запросы в smartdns, а тот — на публичные DNS-серверы по TLS (DoT) или HTTPS (DoH).
Так оператор не видит и не подменяет ответы DNS: DNS оператора выдает для части заблокированных сайтов `127.0.0.2` или пустой ответ.

```text
клиент LAN ──UDP/TCP 53──► br0 ── nat PREROUTING ─► MOD_DNS ─► REDIRECT :5353
                                                                   │
                         dnsmasq (192.168.1.1:5353) ◄──────────────┘
                           ├─ домен из списка рекламы → 0.0.0.0
                           ├─ UPSTREAM=stock  → стоковый DNS 127.0.0.1:53 → DNS оператора
                           └─ UPSTREAM=secure → smartdns 127.0.0.1:5453 → DoH/DoT (1.1.1.1, 8.8.8.8, 9.9.9.9)
клиент LAN ──IPv6, порт 53──► filter INPUT/FORWARD ─► MOD_DNS6 ─► отказ (если BLOCK_DNS6=1)
```

## Файлы

Бинарники в `bin/` кладет [get-bins.sh](../README.md) на компьютере.

| файл | что это |
|---|---|
| `bin/dnsmasq` | dnsmasq 2.93, статическая ARM-сборка без DHCP и TFTP |
| `bin/smartdns` | smartdns Release48.4 из релиза автора, нужен для режима `secure` |
| `bin/curl` | статический curl, нужен только для `svc.sh update` |
| `cacert.pem` | корневые сертификаты (набор Mozilla с curl.se) для проверки серверов DoT, DoH и сайта списка |
| `presets.txt` | список пресетов: серверы, имена TLS, рекомендуемый |
| `svc.sh` | запуск, остановка, состояние, автозапуск, обновление списка |
| `conf` | настройки |
| `lists/block.conf` | список рекламы в формате dnsmasq (`address=/домен/#`), создает `svc.sh update` |
| `lists/allow.txt` | исключения: домены, которые не блокировать, по одному в строке (файл создает пользователь) |
| `enabled` | флаг автозапуска: есть файл — общий автозапуск выполняет `svc.sh start` |
| `/tmp/mod/dns/` | конфиги, PID и журналы dnsmasq и smartdns (в ОЗУ) |

## Команды

| команда | что делает |
|---|---|
| `svc.sh start` | запускает smartdns (если `UPSTREAM=secure`) и dnsmasq, ставит правила |
| `svc.sh stop` | снимает правила, останавливает dnsmasq и smartdns |
| `svc.sh restart` | `stop`, затем `start` |
| `svc.sh status` | печатает `running=0\|1`, `enabled=0\|1`, `info=…`, `preset=`, `preset_label=`, `adblock=0\|1`, `dns_fallback=0\|1`, `dns_upstream=preset\|backup\|operator`, `user_off=0\|1`, `last_error=` |
| `svc.sh enable` | создает флаг автозапуска `enabled`, снимает `DNS_USER_OFF` |
| `svc.sh disable` | удаляет флаг автозапуска, записывает `DNS_USER_OFF=1` |
| `svc.sh vpn-up` | для пакета `awg`: поднимает службу, если нет `DNS_USER_OFF=1` |
| `svc.sh update` | скачивает список по `LIST_URL` и пересобирает `lists/block.conf`; нужен интернет |
| `svc.sh update ФАЙЛ` | то же из файла на роутере, без скачивания |

После `update` работающий dnsmasq перезапускается сам.

## VPN включен, DNS тоже

При запуске туннеля и при его автозапуске пакет `awg` поднимает службу с пресетом `auto`. Правило одно и для раздельного режима, и для полного VPN, со списком российских адресов и без него.

Почему так: с DNS оператора заблокированные сайты не открываются и через туннель. Оператор на них отвечает `127.0.0.2`, `SERVFAIL` или `NXDOMAIN`, и до туннеля дело не доходит. Настоящий адрес через туннель открывается.

| действие | что происходит |
|---|---|
| `start`, `enable`, `restart` | выбор снят: туннель снова будет поднимать службу |
| `stop` работающей службы, `disable` | `DNS_USER_OFF=1`: туннель службу не поднимает |
| `stop` остановленной службы | выбор не меняется: так делает `mod-ctl` перед обновлением |
| `use-preset`, `adblock` | выбор хранится в `settings`, запуск туннеля его не меняет |
| остановка туннеля, смена профиля | служба продолжает работать |

Выбор лежит в `/online/mod/conf/dns/settings`, поэтому обновление и перезагрузка его не сбрасывают. Флаг `enabled` действует отдельно: при `enabled` общий автозапуск поднимает службу и после `stop`, поэтому выключать надо парой `stop` и `disable`, как меню экрана.

## Если серверы не отвечают

Интернет не должен пропасть из-за DNS. Цикл `svc.sh watch` следит за сервером и переключает его без перезапуска dnsmasq. Смена сервера чистит кэш, подмененные ответы оператора в нем не остаются.

| `dns_upstream=` | `dns_fallback=` | куда идут запросы | заблокированные сайты |
|---|---|---|---|
| `preset` | `0` | выбранный пресет | открываются |
| `backup` | `1` | запасные серверы из `FALLBACK_SERVERS`: Quad9 по DoT и DoH, Google по DoH | открываются |
| `operator` | `1` | DNS оператора | не открываются, остальные сайты работают |

DoH идет на порт 443, поэтому запасные серверы работают и при закрытом порте 853. Cloudflare среди них нет: HTTPS к нему напрямую у Tele2 режется, хотя DoT к нему работает.

Цикл не тратит трафик, пока сбоев нет: раз в `WATCH_POLL` он читает счетчики сбоев самого dnsmasq. Настоящий запрос к серверам идет при первом запуске и при появлении сбоя. На запасном пути первые 10 проверок идут раз в `WATCH_POLL`, дальше раз в `FALLBACK_RETRY`. Серверы проверяются только в режиме `secure` при `FALLBACK=1`. При `FALLBACK="0"` и отказе сервера DNS у клиентов не работает.

## Если служба не запустилась

| что случилось | что видит клиент | что показывает `status` | что делает цикл |
|---|---|---|---|
| dnsmasq не запустился | стоковый DNS, то есть DNS оператора: правил `MOD_DNS` нет | `running=0`, `last_error=`, `info=не запустилась, цикл повторяет запуск…` | повторяет раз в `START_RETRY` |
| dnsmasq упал | до `WATCH_POLL` с без DNS, потом как выше | `running=0` | снимает правила, запускает заново |
| smartdns упал | DNS оператора или запасные серверы, `dns_fallback=1` | `running=1` | запускает заново при следующей проверке |
| smartdns долго запускается | так же | `running=1`, в `svc.log` запись с состоянием процесса | ждет 3 минуты, потом запускает заново |

Для панели: `running=0`, `enabled=1`, `user_off=0` значит «должна работать, но не запустилась». Цикл работает, пока пользователь не выключил службу; запуск и остановка идут под локом `/tmp/mod/dns/op.lock`, повторный `start` ничего не ломает.

smartdns идет без своего режима демона (`-f`): тот ждет готовности около 3 с и убивает процесс. При загрузке роутера этого не хватает.

Примерно полминуты после включения заблокированные сайты могут не открываться: служба DNS еще не запущена, клиентам отвечает DNS оператора или никто. Если пресет перестал отвечать позже, клиенты получают запасные серверы или DNS оператора, панель показывает `dns_fallback=1`. Первые `START_WINDOW` секунд после запуска цикл проверяет пресет раз в 10 с, раз в минуту запускает smartdns заново и пишет в `svc.log` строки: сколько свободен процессор, есть ли маршрут и открыт ли порт сервера.

Смены сервера пишутся в `/tmp/mod/dns/svc.log`.

## Пресеты: выбор сервера

Команды для панели и меню экрана. Код 0 — успех, 1 — ошибка, текст ошибки одной строкой в stderr.

| команда | что делает |
|---|---|
| `svc.sh presets` | строки `id\|подпись\|активный`, активный — `0` или `1`; первой идет `auto` |
| `svc.sh use-preset ID` | запоминает пресет; если служба запущена, применяет сразу; сама службу не запускает |
| `svc.sh set-custom АДРЕС` | адрес для пресета `custom`: `https://сервер/dns-query`, `tls://имя` или IPv4 (без шифрования) |
| `svc.sh adblock on\|off` | включает или выключает блокировку рекламы, сервер не меняется |
| `svc.sh brief` | одна строка `running=0\|1\|preset=ID\|label=ПОДПИСЬ\|adblock=0\|1\|fallback=0\|1` |

| пресет | куда идут запросы |
|---|---|
| `auto` | рекомендуемый из `presets.txt` |
| `cloudflare-dot`, `quad9-dot`, `google-dot`, `yandex-dot`, `adguard-dot` | DoT, порт 853 |
| `cloudflare-doh`, `quad9-doh`, `google-doh`, `yandex-doh`, `adguard-doh` | DoH, порт 443 |
| `operator` | DNS оператора через стоковый DNS роутера, без шифрования; на заблокированные домены отдает `127.0.0.2` или ошибку |
| `custom` | адрес из `CUSTOM_DNS` |

Обычного DNS (порт 53) в пресетах нет, кроме `operator`: запросы к 8.8.8.8 и 1.1.1.1 у Tele2 перехватываются, на заблокированные домены приходит `NXDOMAIN`. Для Google и Cloudflare выбирайте DoT или DoH.
Выбор хранится в `/online/mod/conf/dns/settings` (`PRESET`, `CUSTOM_DNS`, `ADBLOCK`, `DNS_USER_OFF`, права 0644, секретов нет) и читается поверх `conf`. Установка новой версии пакета его не сбрасывает.
Пресеты AdGuard сами блокируют рекламу: `adblock off` на них не отключает блокировку на стороне сервера.
Для `https://` и `tls://` в `custom` нужно имя сервера, а не адрес: сертификат проверяется по этому имени. Адрес имени узнается через рекомендуемый пресет, поэтому такой сервер отвечает примерно через 6 с после применения.
Выбор применяется за 1–2 с, `adblock` — меньше чем за 0,5 с. На это время DNS-запросы клиентов не получают ответа.

На Tele2 `custom` с `https://cloudflare-dns.com/dns-query` не отвечает, причина не установлена. Пресет `cloudflare-doh` работает.

## Настройки `conf`

| ключ | по умолчанию | что делает |
|---|---|---|
| `IFACE_LAN` | `br0` | интерфейс клиентов |
| `PORT` | `5353` | порт dnsmasq на адресе `br0` |
| `PRESET` | `auto` | пресет сервера, выбор — в `settings`; если ключ пуст, работают `UPSTREAM` и `SECURE_SERVERS`, как записаны (`preset=manual`) |
| `CUSTOM_DNS` | пусто | адрес для пресета `custom`, выбор — в `settings` |
| `UPSTREAM` | `secure` | `stock` — DNS оператора; `plain` — серверы из `PLAIN_SERVERS`; `secure` — DoT и DoH через smartdns. При выбранном пресете вычисляется из него |
| `PLAIN_SERVERS` | пусто | серверы для `plain`, через пробел |
| `SECURE_SERVERS` | см. файл | серверы для `secure`: `tls://АДРЕС#ИМЯ` или `https://АДРЕС/ПУТЬ#ИМЯ`. При выбранном пресете вычисляется из него |
| `SECURE_PORT` | `5453` | порт smartdns на `127.0.0.1` |
| `DNS_USER_OFF` | `0` | `1` — пользователь выключил службу, выбор — в `settings` |
| `FALLBACK` | `1` | при отказе серверов переходить на запасные и на DNS оператора |
| `FALLBACK_SERVERS` | см. файл | запасные серверы, формат как у `SECURE_SERVERS` |
| `BACKUP_PORT` | `5454` | порт smartdns для запасных серверов на `127.0.0.1` |
| `START_WINDOW` | `300` | сколько секунд после запуска проверять серверы чаще |
| `START_RETRY` | `60` | как часто повторять запуск, если служба не поднялась, с |
| `WATCH_POLL` | `20` | как часто читать счетчики сбоев, с |
| `FALLBACK_RETRY` | `120` | как часто пробовать пресет на запасном пути после первых 10 попыток, с |
| `ADBLOCK` | `1` | блокировать домены из `lists/block.conf`, выбор — в `settings` |
| `LIST_URL` | HaGeZi Light | откуда `update` скачивает список |
| `LIST_MAX` | `100000` | сколько доменов брать из списка, не больше |
| `FORCE` | `1` | `1` — перехватывать запросы к любым DNS-серверам, `0` — только к роутеру |
| `BLOCK_DNS6` | `1` | отказ на DNS-запросы клиентов по IPv6 |
| `CACHE` | `1000` | размер кэша dnsmasq, записей |

`ИМЯ` в `SECURE_SERVERS` — имя в сертификате сервера. smartdns сверяет его по `cacert.pem`.
Для проверки сертификата нужны верные часы роутера.

Список понимает строки трех видов: `домен`, `0.0.0.0 домен` (формат hosts) и `||домен^` (формат AdGuard).
Блокируется домен вместе со всеми поддоменами.

## Правила iptables

| программа, таблица | цепочка | откуда переход | что делает |
|---|---|---|---|
| `iptables`, `nat` | `MOD_DNS` | `PREROUTING`, первым, `-i br0` | UDP и TCP 53 — на порт `PORT` |
| `ip6tables`, `filter` | `MOD_DNS6` | `INPUT` и `FORWARD` (при `FORCE=1`), первым, `-i br0` | отказ для UDP и TCP 53 |

`stop` снимает правила целиком. Переход в `MOD_DNS` стоит раньше стоковой цепочки `PRE_REDIRECT`,
которая без сети перехватывает весь DNS на стоковый DNS.

## Проверка

На роутере:

```sh
/online/mod/pkg/dns/svc.sh update
/online/mod/pkg/dns/svc.sh start
/online/mod/pkg/dns/svc.sh status
```

На компьютере в LAN:

```sh
dig @192.168.1.1 ДОМЕН_ИЗ_СПИСКА +short    # ожидаемо 0.0.0.0
dig @192.168.1.1 ya.ru +short              # обычный адрес
```

## Ограничения

- Только IPv4: для IPv6 нет NAT, поэтому DNS по IPv6 отклоняется, а не перенаправляется.
- Браузеры со своим шифрованным DNS (DoH в настройках браузера) идут мимо фильтра.
- Сам роутер (часы, обновления) спрашивает стоковый DNS, не этот фильтр.
- Публичные серверы DoT (порт 853) оператор может блокировать. Служба сама перейдет на запасные серверы; если это надолго, выберите пресет DoH.
- Если туннель AmneziaWG запущен с `dns on`, после смены пресета выполните `svc.sh dns on` пакета `awg`: так обновятся маршруты к серверам DNS.
- Отсечение по `LIST_MAX` идет после сортировки по алфавиту: если список длиннее, часть доменов в конце алфавита не попадет.
- Один запрос после простоя стоит около 17 КБ: два сервера пресета, у каждого новое соединение TLS. Запросы из кэша наружу не идут.
- Домен из списка рекламы мешает сайту: добавьте его в `lists/allow.txt`, потом `svc.sh restart`.
