# Установка одной командой

`install-all.sh` ставит веб-панель, меню экрана и по желанию логотип на роутер, где уже стоит мод bay v5. Для того, кто не хочет проходить инструкции вручную; они остаются подробностями: [панель](../webui/README.md), [меню](oled-menu.md), [логотип](boot-logo.md).

Скрипт вызывает проверенные установщики этих частей. Прошивку, NV и загрузчики он не трогает. Чистый роутер: сначала [восстановление](recovery.md), потом [NV](nv-fix.md), если ставилась прошивка 22c.

## Что нужно

| что | как получить |
|---|---|
| мод bay v5 на прошивке 21.191.63.02 и `modwebui_1.5a` | [восстановление](recovery.md) |
| вход по SSH с ключом ECDSA | [пункт «Ключ SSH»](oled-menu.md#вход-по-ssh) |
| ключ хоста роутера в файле ключей под именем `e5785-router` | первый вход с `-o HostKeyAlias=e5785-router`, см. [панель](../webui/README.md) |
| бинарники пакетов панели | `webui/src/pkg/get-bins.sh`, для модуля ядра с `--module` |
| на компьютере `ssh`, `tar`, `curl`, `ip`, `python3`, для логотипа Pillow | пакеты системы |
| роутер подключен по USB | маршрут к `192.168.1.1` идет через `wwx001e101f0000`, другой интерфейс — ключ `--iface` |

Ключ SSH и файл ключей хостов задаются переменными окружения:

```bash
export ROUTER_KEY=~/.ssh/e5785
export ROUTER_KNOWN_HOSTS=~/.ssh/known_hosts
```

## Команды

```bash
./install-all.sh --dry-run            # проверки, план и ответы установщиков
./install-all.sh                      # панель и меню
./install-all.sh --reboot             # то же, перезагрузка и повтор проверки
./install-all.sh --logo --dry-run     # то же с логотипом, без записи
./install-all.sh --logo               # только логотип, спросит подтверждение
```

| ключ | что делает |
|---|---|
| `--panel`, `--menu`, `--logo` | части; без этих ключей панель и меню, логотип только по явному ключу |
| `--dry-run` | ничего не меняет на флеше: файлы проверки лежат в `/tmp` роутера и убираются |
| `--reboot` | перезагружает роутер в конце, ждет его до 180 с и повторяет проверку |
| `--pkgs=СПИСОК` | пакеты панели через запятую, например `--pkgs=awg,dns`; по умолчанию все, у которых есть `bin` |
| `--no-sms` | меню без компонента SMS и USSD |
| `--logo-image=ФАЙЛ` | свой PNG 128×128 вместо `boot/logo/logo3_A.png` |
| `--yes` | не спрашивать подтверждение логотипа |
| `--host=АДРЕС`, `--iface=ИМЯ` | адрес роутера и интерфейс компьютера |

Коды выхода: 0 — успех, 1 — отказ проверки или шага, 2 — неверный ключ.

## Что делает скрипт

1. Проверяет файлы на компьютере: установщики, бинарники, контрольные суммы набора меню.
2. Читает роутер, ничего не меняя: плата `E5785Lh-23c`, раздел `app` размером `013c0000`, имя продукта, прошивка 21.191.63.02, файлы мода, место в `/app` и `/online`. Если что-то не так, останавливается и пишет, что делать.
3. Показывает план.
4. Панель: `install.sh --only=web,api`, затем пакеты по одному: на `/online` мало места для всех сразу.
5. Меню: копирует набор в `/online/hij_install`, запускает `mk_oled_cfg.sh`, `DRY=1`, затем `install.sh` с `SMS=1`.
6. Логотип, если задан `--logo`: читает раздел на компьютер в `logo-backup-ДАТА.bin`, спрашивает подтверждение, пишет, читает назад и сверяет байт в байт.
7. Проверяет результат как в разделе [«Проверка»](install.md#проверка): панель отвечает http 200, помощник работает, состояние VPN, файл меню совпадает с `MANIFEST`.
8. Печатает команды отката каждой части и напоминает о перезагрузке: меню и логотип заработают после нее.

При первой ошибке скрипт останавливается. Части, которые уже поставлены, остаются, и он печатает их откат.

## Откат

| часть | команда |
|---|---|
| панель | `webui/src/installer/rollback.sh`, только последняя установка: `--last` |
| меню | `ssh root@192.168.1.1 'busyboxx sh /online/hij_install/rollback.sh'` и перезагрузка |
| логотип | команды печатает сам скрипт, копия раздела в `logo-backup-ДАТА.bin` |

## Ограничения

- Настоящая установка этим скриптом на роутере не запускалась, в том числе ветка `--reboot` и запись логотипа. Проверены 35 случаев на заглушках `ssh`, `curl`, `ip` и установщиков (`packaging/test/test_install_all.sh`) и настоящий `--dry-run` всех трех частей на роутере, где они уже стояли.
- Настоящая установка из `prebuilt/` на роутер и сверка sha256 с программами на роутере не проверялись.
- Установка на чистый роутер не проверялась: см. [«Проверка»](install.md#проверка).
- Проверка места грубая, точный подсчет — в установщиках частей. Запись они не начинают, если места не хватает.
