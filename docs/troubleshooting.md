# Частые проблемы и грабли

Таблицы для того, кто уже что-то делает с роутером и уперся. Подробности — в [восстановлении](recovery.md), [исправлении NV](nv-fix.md) и [меню экрана](oled-menu.md).

## Запись и загрузка

| признак | причина | что сделать |
|---|---|---|
| после записи черный экран, USB нет | `OKAY` по смещению `0x2000` образа: перед записью в сеансе были чтения | новый вход в BootROM, запись сразу после подъема fastboot, сверка `verify_flash.py` |
| `flash system` дает `flash write failure` | в прошивке `System.bin` — архив cpio | образ `mkyaffs_hw.py`, перед записью `erase` |
| после записи YAFFS2 старые файлы видны, система странная | старые блоки перекрывают новые: не было `erase` | `fastboot erase РАЗДЕЛ`, запись заново |
| в дампе блок повторяет предыдущий | плохой блок, fastboot его пропустил; в `app` на проверенном роутере это блоки 51 и 53 | не ошибка, `verify_flash.py` его пропускает |
| `fastboot reboot` снова приводит в режим прошивки | теплый перезапуск, флаг `NFLD` остается | вынуть аккумулятор, включить кнопкой |
| `balong_flash` дает ошибку `0c` на разделе `System` | штатная запись по HDLC на 23c после чужой прошивки не проходит: подпись `System` | писать через fastboot в памяти ([инструкция](recovery.md)) |
| `fastboot` отвечает не тот | попал на сканер отпечатков или другое устройство | указать порт: `-s usb:1-2`, узнать его в `fastboot devices -l` |
| экран черный, остальное работает | раздел `webui` пуст: программа экрана берет ресурсы из веб-интерфейса | записать `webui` |

## Сеть и NV

| признак | причина | что сделать |
|---|---|---|
| нет сети, RSRP −122 дБм | NV эталонной платы | [исправление NV](nv-fix.md) |
| роутер выключается сам, журнал `thermal protection [352 ...]` | `nvsys` старый | [шаги 5–9](nv-fix.md#порядок) |
| заблокированные сайты не открываются первые полминуты после загрузки | служба DNS еще не запущена | подождать; первая загрузка без файла запаса случайных чисел дает около 3 минут |
| смена Wi-Fi дает код `100006` | имя продукта пустое, обработчик ищет `/app/config/wifi/configure.xml` | исправление NV; без него — копия `/app/config/E5785Lh-23c/wifi` в `/app/config/wifi` |
| `AT^NVWR` и `AT^NVRD` дают ошибку | `^DATALOCK:1`, патч мода не работает на этом ядре | `balong-nvtool` |
| `dd` в `/dev/nv` дает `Operation not permitted` | NV 36 запрещена в ядре | индекс 93, NV 50018 |
| `balong-nvtool -w` записал не все | берет только файлы с 5-значным именем | `-r` по ячейкам, это делает `apply.sh` |
| порт `/dev/ttyUSB0` не отвечает на `AT+COPS?` | порт урезан: только `ATI`, `AT^DATALOCK?` и уведомления | внутри роутера: `/system/xbin/atc "КОМАНДА"` |

## Меню экрана

| признак | причина | что сделать |
|---|---|---|
| `install.sh`: «нет файла набора .../oled_cfg/menue.xml» | не запущен `mk_oled_cfg.sh` | запустить его |
| `install.sh`: «текущие файлы отличаются от известных» | на роутере не мод bay v5 или файлы менялись | проверить вручную; `FORCE=1`, если уверены |
| `mk_oled_cfg.sh`: md5 не совпадает | веб-интерфейс не 21.100.52.00.03 и не `modwebui_1.5a` | поставить один из них |
| нет пункта «Тест скорости», «VPN» или «DNS» | нет файлов веб-панели | поставить [веб-панель](../webui/README.md) |
| нет пункта «SMS и USSD» | компонент SMS не ставился или `sms` еще не перезапущен | `SMS=1`, перезагрузка, `check_sms.sh` |
| родной экран вместо своего | есть `/online/mod/conf/oled_home_off` или другая сборка `oled` | убрать файл; другая сборка не поддерживается |
| скрипт меню не видит сеть | процессы uid 1000 не открывают сокеты | скрипты меню идут от root: проверить `/var/hijack_bootanim.log` |
| меню собрано, а пункта «Расширенные» нет | сборка без флагов | собирать через `build_r10.sh` |

## Доступ

| признак | причина | что сделать |
|---|---|---|
| нет входа по SSH с ключом ed25519 | dropbear 2019.78 его не знает | ключ ECDSA |
| `192.168.1.1` не отвечает, интерфейса `wwx...` нет | роутер в режиме зарядки (`12d1:1c20`) или на компьютере другой маршрут | включить роутер; проверить `ip route get 192.168.1.1` |
| роутер не переходит с `12d1:15ca` на `1506` | компьютер сам переключает его через `usb_modeswitch` | проверить запись `usb_modeswitch` для Huawei; после прерванных скриптов — `DisableSwitching` |
| веб-интерфейс отвергает запрос | принимается только `Host` `192.168.1.1` или текущее имя | мост `tools/bridge/e5785_webproxy.py` при пробросе |
| `reboot` молчит | на роутере `reboot` — toolbox, `setsid` нет в `PATH` | `busyboxx setsid busyboxx sh -c "sleep 2; sync; busyboxx reboot -f" &` |
| `pkill -f ШАБЛОН` по ssh обрывает соединение | шаблон лежит в командной строке самой оболочки | `pgrep` и `kill` по PID |

## Что не делать

| действие | чем плохо |
|---|---|
| ставить прошивки 22c на 23c | другая раскладка, чужой NV, белый экран |
| ставить `anti_ttl1_patch` на мод bay v5 | патч `cms` по смещению: другая сборка дает бесконечную перезагрузку |
| вызывать `oem efuse` с записью | необратимо |
| писать копию из `nanddump` через `rawflash_ex` | портит ECC |
| выполнять `AT^INFORBU` | перезаписывает заводскую копию NV |
