[b]Для кого[/b]
Только E5785Lh-23c (плата CL1E5785SM VER.A, dload id E5785__0). На 22c ставить нельзя: другой экран, другая кнопка сброса, другая раскладка разделов. Все делаете на свой риск. Перед записью снимайте копии NV.

[b]Что есть[/b]
[list]
[*]Восстановление из режима прошивки: fastboot в памяти, сверка байт в байт, ловушка OKAY по смещению 0x2000
[*]Исправление NV после прошивки от 22c: секция product_id=33 из официального пакета, сброс nvsys через /dev/nv
[*]Ложные выключения от перегрева: причина и проверка
[*]Меню экрана на основе huawei_oled_hijack_ng: свой главный экран, значки, VPN, DNS, игра «Орбита»
[*]Логотип и анимация «Поехали!»
[*]Веб-панель: AmneziaWG, обход DPI, шифрованный DNS, блокировка рекламы, тест скорости
[*]Экспериментальный модуль AmneziaWG для ядра 3.10
[/list]

[b]Что нужно[/b]
[list]
[*]Прошивка 21.191.63.02 с модом bay v5 и modwebui_1.5a (тема 907081, посты 95373571 и 80753809)

Файлов Huawei и мода в комплекте нет, скрипты правят ваши копии.

[b]Порядок[/b]
Все шаги и подробности: docs/pdf/e5785lh-23c-install.pdf, все возможности: docs/pdf/e5785lh-23c-features.pdf. Роутер не загружается или стоит стоковая прошивка: docs/recovery.md. Ставилась прошивка 22c: docs/nv-fix.md.
Мод уже стоит:
[code]webui/src/pkg/get-bins.sh
./install-all.sh --dry-run
./install-all.sh[/code]
Скрипт проверяет модель и мод, останавливается при первой ошибке, печатает команды отката. Логотип только по ключу --logo, с подтверждением. Меню заработает после перезагрузки: ключ --reboot или вручную.

[b]Что проверено[/b]
Проверено пользователем на одном роутере: все пункты меню экрана, включая VPN, «Свои скрипты», «РФ напрямую», DNS и «Орбиту», главный экран, логотип и анимация, страницы панели и сохранение настроек.

[b]Что не проверено[/b]
Обычной работой это не проверяется:
[list]
[*]Установка комплекта на чистый роутер и установка мода со стоковой прошивки
[*]Настоящая установка скриптом install-all.sh, ветка --reboot, запись логотипа этим скриптом: на роутере выполнен только --dry-run
[*]Настоящая установка из prebuilt/ на роутер и сверка sha256 с программами на роутере
[*]get-bins.sh --fetch, --via=jump, синтаксис Lua через luac
[*]Загрузка готовым balong-usbdload, flash_fw.sh, значения NV из XML
[*]Смена профиля с настоящими порогами 180, 300 и 1800 с: проверена с сокращенными
[*]Запасной переход на amneziawg-go: переход и связь с сервером есть, выход в интернет не подтвержден
[*]Раздельный VPN с приложениями банков на телефоне
[*]Долгая работа
[/list]

[b]Чего ждать[/b]
[list]
[*]Скорость: напрямую до 105 Мбит/с, через VPN 21-46 Мбит/с в зависимости от сервера и потоков (упор в процессор), один поток 7-22
[*]Раздельный VPN и смена профиля включены по умолчанию. Без загруженного списка это обычный полный VPN. Список получаете сами через split-gen.py, условия RIPE читайте сами, это не юридическое заключение
[*]DNS включается вместе с VPN, если не выключен вручную; запасные серверы при отказе DoT
[*]После загрузки настоящие адреса примерно через полминуты; первая загрузка без файла запаса случайных чисел дает около 3 минут
[*]Лимита заряда нет: встроенная защита есть по именам функций в ядре, не измерена
[/list]

[b]Важно[/b]
Модуль ядра не выгружайте: при пакетах в очереди модема это паника ядра. Остановка только через ip link del, откат перезагрузкой.
/online принадлежит uid 1000, поэтому процесс с этим uid может подменить /online/mod и получить root.
