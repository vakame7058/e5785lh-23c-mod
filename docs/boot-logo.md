# Логотип и анимация

Для того, кто хочет поменять картинки загрузки. Их две: логотип загрузчика и анимация в программе экрана. Обе ставятся отдельно от прошивки и откатываются без иголки.

| что | когда видно | где лежит | формат |
|---|---|---|---|
| логотип | первые ~15 с после включения | раздел `logo`, `/dev/block/mtdblock20` | 128×128 RGB565, старший байт первым, 32768 Б |
| анимация | сразу за логотипом, один раз на загрузку | `/app/hijacks/bootanim/frames.bin`, `durations` | кадры как у логотипа, длительность в мс — по строке на кадр |

Логотип и анимация проверены пользователем на одном роутере. Готовые файлы: логотип «Подготовка...» — [`boot/logo/logo3_A.png`](../boot/logo/logo3_A.png), анимация «Поехали!» на 66 кадров, 4320 мс — [`boot/anim/`](../boot/anim/). Генераторы — [`boot/gen/`](../boot/gen/).

## Логотип

Раздел `logo` занят на 64 КиБ из 1 МиБ. Слот [0], первые 32768 Б, — картинка заводского режима. Слот [1] — обычная загрузка. Меняйте только слот [1].

1. Снимите копию раздела (на компьютере):

   ```bash
   ssh root@192.168.1.1 'busyboxx dd if=/dev/mtd/mtd20 bs=65536 count=1' > logo_backup.bin
   ```

2. Соберите образ. PNG 128×128 сводится к RGB565 усечением младших бит:

   ```bash
   python3 tools/logo/mklogo.py boot/logo/logo3_A.png logo_backup.bin logo_new.img
   ```

3. Запишите образ и сверьте (на компьютере). Сперва файл во временный каталог: `dd` с `count=1` из канала SSH может записать неполный блок.

   ```bash
   ssh root@192.168.1.1 'busyboxx dd of=/tmp/logo_new.img' < logo_new.img
   ssh root@192.168.1.1 'busyboxx dd if=/tmp/logo_new.img of=/dev/block/mtdblock20 bs=65536 count=1 conv=notrunc && busyboxx sync'
   ssh root@192.168.1.1 'busyboxx dd if=/dev/mtd/mtd20 bs=65536 count=1' | cmp - logo_new.img
   ```

   Пустой вывод `cmp` — запись совпала. Логотип появится при следующей загрузке.

Одной командой: [`install-all.sh --logo`](install-all.md), с подтверждением, копией раздела и сверкой. Откат — та же запись из `logo_backup.bin`. Из режима fastboot логотип пишется так: `fastboot flash logo logo_new.img`.

Если первая запись дала розовую полосу и странные цвета, байты в пикселе переставлены: нужен старший байт первым. Посмотреть содержимое образа: `mklogo.py --show logo_new.img out`.

## Анимация

Анимация входит в [набор меню экрана](oled-menu.md). Чтобы заменить ее своей:

1. Подготовьте PNG 128×128 и список длительностей.
2. Соберите кадры:

   ```bash
   mkdir out
   python3 boot/gen/mkbootanim.py out 60,60,70,1500 кадр0.png кадр1.png кадр2.png кадр3.png
   ```

   `mkbootanim.py` сверяет результат с PNG. Младшие биты теряются, скрипт пишет, в скольких пикселях.

3. Замените `frames.bin` и `durations` в `/app/hijacks/bootanim/`:

   ```bash
   ssh root@192.168.1.1 'busyboxx mount -o remount,rw /dev/block/mtdblock24 /app'
   scp out/frames.bin out/durations root@192.168.1.1:/app/hijacks/bootanim/
   ssh root@192.168.1.1 'busyboxx sync; busyboxx mount -o remount,ro /dev/block/mtdblock24 /app'
   ```

Предел — 128 кадров. Кадры читаются по одному перед показом, поэтому длина анимации старт программы экрана не задерживает.

Как анимация себя ведет:

| событие | что происходит |
|---|---|
| последний кадр отыграл или нажата кнопка | кадр держится до первого кадра родной программы, отличного от заставки; без него через 1,5 или 8 с показывается запомненный кадр |
| родная программа погасила экран | анимация останавливается |
| нет `frames.bin` | показывается родная заставка |
| режим зарядки выключенного роутера | анимации нет |
| перезапуск программы без перезагрузки роутера | анимации нет: метка `/var/hijack_bootanim_shown` живет до перезагрузки |
| есть файл `/app/hijacks/bootanim/debug` | журнал пишется в `/var/hijack_bootanim.log`, до 64 КиБ |

## Свои картинки по образцу

Генераторы в `boot/gen/` рисуют кадры на Pillow, шрифт DejaVu Sans Bold берут из `/usr/share/fonts/truetype/dejavu`. Запускайте их из отдельного пустого каталога: они пишут PNG в текущий каталог.

| скрипт | что делает |
|---|---|
| `anim.py`, `anim2.py` | общие функции сцены: небо, ракета, площадка |
| `anim4.py` | кадры `poehali4_*.png` и `poehali4_durations`, то есть готовую анимацию |
| `logo2.py`, `logo3.py` | варианты логотипа, `logo3_A.png` — готовый |
| `home.py` | макеты главного экрана |
| `mkbootanim.py` | PNG в `frames.bin` и `durations` |

Кадры повторяются при каждом запуске: случайные числа заданы явно.

## Ограничения

- Менять `logo` через `dd` можно только из работающей системы мода: нужен root.
- Слот [0] не проверялся в заводском режиме после записи. `mklogo.py` оставляет его как в базе.
